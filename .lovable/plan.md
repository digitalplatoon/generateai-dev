# GenerateAI.dev Logo and Favicon

## What will change
- Create a crisp, geometric GenerateAI.dev logo mark that combines a stylized “G”, code brackets, and an AI node motif.
- Keep the existing teal-led brand palette and ensure the mark remains clear in both dark and light themes.
- Replace the temporary brain icon in the site header and the generic “G” block in the footer with one reusable logo component.
- Create a matching square SVG favicon and connect it to browser tabs and saved-device icons.
- Remove the obsolete favicon after the new mark is active.

## Quality checks
- Verify the logo at header, footer, and favicon sizes.
- Check desktop and mobile layouts in both themes.
- Confirm the home page renders without browser errors and the new favicon is served successfully.

## Technical details
- The logo will be an accessible inline SVG so it stays sharp at every screen size and inherits semantic theme colors.
- The favicon will be a standalone optimized SVG in the public assets folder.
- Existing navigation, content, and application behavior will remain unchanged.
